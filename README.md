# Swinging Shooters

A fast-paced first-person shooter built around fluid grapple-and-swing movement. Chain together grapple hooks to fly across arenas, outmaneuver hostile turrets, and clear every enemy standing between you and the final boss.

---

## Controls

| Action | Input |
|---|---|
| Move | WASD |
| Sprint | Hold Left Shift |
| Jump | Space |
| Look | Mouse |
| Shoot | Hold Left Click |
| Grapple | Hold E |
| Swing | Hold Q |
| Equip Pistol | 1 |
| Equip Rifle | 2 |
